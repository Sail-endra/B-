# UI/UX FREEZE

The Course Copilot UI/UX is frozen after the final product-polish pass.

Do not modify the application's visual design, layout, styling, navigation,
component appearance, spacing, typography, colors, animation, or interaction
patterns unless the user explicitly requests a UI/UX change.

Future technical work may change bugs, backend behavior, AI logic, retrieval,
data processing, performance, security, tests, and API integrations without
changing the established interface. If a technical change genuinely requires a
UI change, stop and tell the user before making that visual change.

Do not make incidental UI improvements during unrelated work. Treat this rule as
an explicit product constraint, even when a different interface might seem
preferable.
